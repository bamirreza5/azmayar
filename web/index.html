شروع کار با آزمایار

این برنامه روی کامپیوتر شما اجرا می‌شود. رابط در مرورگر باز می‌شود و کد مقصد داخل Docker اجرا خواهد شد.

  1. Python 3.11 یا جدیدتر، Git و Docker Desktop را نصب کنید. در ویندوز، Docker را روی Linux containers بگذارید.
  2. فایل run_windows.bat یا run_linux_mac.sh را اجرا کنید.
  3. آدرس مخزن عمومی را وارد و «شروع آزمون» را بزنید. در اجرای اول تصویر مرورگر دانلود و ساخته می‌شود.
  4. نتایج، نمودار منابع، تصاویر و گزارش قابل دانلود را بررسی کنید.

پروفایل Django خودکار از دیتابیس SQLite تازه استفاده می‌کند. برای دیتابیس دیگر، ورود سفارشی، یا گردش کار ثبت و ارجاع نامه، فرمان و سناریو را در تنظیمات پیشرفته وارد کنید. Node از npm پشتیبانی می‌کند؛ شروع سرور باید روی پورت 8765 باشد.

فقط مخازنی را اجرا کنید که به آن‌ها اعتماد دارید. کانتینر دسترسی اینترنت دارد و مرز امنیتی مطلق نیست. رمز یا دیتابیس تولید را به تنظیمات آزمایش ندهید.
