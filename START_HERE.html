REPOSITORY TEST LAB · v1.0.0

آزمایار

تست برنامه از روی مخزن گیت، با رابط فارسی، گزارش خطا و پایش منابع.

راه‌اندازی در ویندوز

  1. پیش‌نیازها را نصب کنید: Python 3.11+، Git و Docker Desktop.
  2. Docker Desktop را باز کنید و منتظر آماده‌شدن موتور Linux بمانید.
  3. در همین پوشه، روی run_windows.bat دوبار کلیک کنید. رابط به صورت خودکار در مرورگر باز می‌شود.
  4. آدرس مخزن را وارد و «شروع آزمون» را بزنید. اجرای اول برای دانلود محیط مرورگر زمان بیشتری می‌خواهد.

آدرس رابط پس از اجرا: http://127.0.0.1:8877

برای دیدبان، از بخش تنظیمات پیشرفته فایل examples/dideban.json را وارد کنید؛ این نمونه، سناریوی ثبت و جست‌وجوی مشتری هم دارد.

راهنمای کامل: README_FA.md · حدود راستی‌آزمایی: VERIFICATION_FA.md · گزارش اجرای آزمایشی دیدبان

نسخهٔ محلی به Docker نیاز دارد. همهٔ خطاهای کسب‌وکار به صورت خودکار کشف نمی‌شوند؛ برای ثبت، ارجاع و تأیید نامه باید تست یا سناریوی اختصاصی تعریف کنید. اجرای کامل کانتینر و پایش واقعی منابع در محیط ساخت این بسته قابل تأیید نبود؛ جزئیات بررسی‌ها داخل پوشه docs آمده است.
