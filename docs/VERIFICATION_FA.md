# راستی‌آزمایی نسخهٔ 1.0.0

تاریخ بررسی: ۲۹ اکتبر ۲۰۲۶

این فایل تفاوت میان «پیاده‌سازی قابلیت» و «اجرای واقعی بررسی آن در محیط ساخت» را ثبت می‌کند.

## انجام‌شده

- ۳۷ تست خود ابزار با `unittest` موفق شدند. اعتبارسنجی ورودی، منع مسیر بیرونی، توقف فرایند ساکت، مهلت کل اجرا، تفکیک منابع، محاسبهٔ CPU و RSS با دادهٔ کنترل‌شده، گزارش HTML، CSV، بازیابی اجرای ناتمام، API محلی و جلوگیری از درخواست نامعتبر بررسی شده‌اند.
- آزمون HTTP با سرور واقعی آزمایشی اجرا شده است: ورود با Cookie، پاسخ 500 و پاسخ 200 که به login برگشته باشد، به درستی از هم تشخیص داده می‌شوند.
- کد JavaScript با `node --check`، Python با compileall و راه‌انداز Bash با `bash -n` بررسی شد.
- رابط فارسی در مرورگر بررسی شد؛ منوها، تنظیمات پیشرفته، افزودن سناریوی دیدبان، وضعیت پیش‌نیازها و صفحهٔ منابع قابل استفاده بودند. بررسی رابط، دادهٔ ساختگی آزمون به تاریخچه اضافه نکرده است.
- مخزن عمومی دیدبان واقعاً دریافت و در یک محیط مجازی Python موقت اجرا شد. تنظیمات آزمایشی و دیتابیس SQLite مستقل استفاده شد.

## در این محیط تأیید نشد

- موتور Docker در دسترس نبود. تصویر نهایی ساخته و زنجیرهٔ کامل clone → Docker → Chromium → گزارش، از ابتدا تا انتها در کانتینر اجرا نشد.
- Chromium داخل worker اجرا نشد؛ ورود Playwright، بازدید خودکار، تصاویر و سناریوی ثبت مشتری پیاده‌سازی شده‌اند، ولی در بررسی محلی دیدبان اجرای واقعی آن‌ها تأیید نشده است.
- فضای نام فرایند این محیط، PID سرور آزمایشی را برای psutil قابل مشاهده نمی‌کرد. اندازه‌گیری واقعی CPU و RAM این اجرا تأیید نشده است. منطق محاسبهٔ منابع با دادهٔ کنترل‌شده تست شده و مقدارِ فاقد نمونه، نامعلوم گزارش می‌شود.
- راه‌انداز `.bat` در Windows واقعی اجرا نشده است. بازبینی راه‌انداز و سازگاری مسیرها انجام شده؛ برای تأیید نهایی باید روی دستگاه Windows دارای پیش‌نیازها اجرا شود.
- پروفایل Node و Python عمومی، قابلیت‌های آمادهٔ برنامه‌اند؛ تست نهایی روی مخزن واقعی Node / Flask / FastAPI در این بررسی انجام نشده است.

## تأیید نهایی روی سیستم اجراکننده

Docker را روشن کنید، برنامه را با راه‌انداز اجرا کنید، preset دیدبان را وارد کنید و آزمون کامل بگیرید. گزارش باید تست‌های مخزن، ورود، بررسی صفحات، سناریوی ثبت مشتری، تصاویر، فشار و نمونه‌های منابع برنامه و کانتینر را نشان دهد. اگر مرحله‌ای اجرا نشد یا وابستگی محیط شکست خورد، نتیجهٔ همان مرحله را ملاک قرار دهید.

این نسخه یک ابزار پایهٔ قابل توسعه است. بدون تست یا سناریوی مناسب، همهٔ منطق اختصاصی اتوماسیون اداری را از روی آدرس مخزن کشف و ارزیابی نمی‌کند.
